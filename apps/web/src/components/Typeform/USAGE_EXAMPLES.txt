=====================================

  TypeformTextarea,

  TypeformGridOptions,
  TypeformProgressBar,

  TypeformStatCard,

EJEMPLO 4: Form Conversacional
==============================

function MyFormPage() {
  const [step, setStep] = useState<'welcome' | 'form' | 'confirm'>('welcome')
  const [name, setName] = useState('')

  const handleNext = () => {
    if (step === 'welcome') setStep('form')
    else if (step === 'form' && name) setStep('confirm')
  }

  return (
    <TypeformContainer>
      {step === 'welcome' && (
        <TypeformCard>
          <TypeformHeading>¡Hola!</TypeformHeading>
          <p>Responde algunas preguntas</p>
          <TypeformButton onClick={handleNext}>Comenzar →</TypeformButton>
        </TypeformCard>
      )}

      {step === 'form' && (
        <TypeformCard>
          <TypeformHeading>¿Cuál es tu nombre?</TypeformHeading>
          <TypeformInput
            value={name}
            onChange={(e) => setName(e.target.value)}
            placeholder="Tu nombre..."
            autoFocus
          />
          <div className="flex gap-4">
            <TypeformButton variant="outline" onClick={() => setStep('welcome')}>
              Atrás
            </TypeformButton>
            <TypeformButton onClick={handleNext} disabled={!name}>
              Continuar →
            </TypeformButton>
          </div>
        </TypeformCard>
      )}

      {step === 'confirm' && (
        <TypeformCard>
          <TypeformHeading>¡Listo!</TypeformHeading>
          <p>Tu nombre es: {name}</p>
        </TypeformCard>
      )}
    </TypeformContainer>
  )
}

GRADIENTES VIBRANTES
====================

Para cards y botones, usa estos gradientes:

from-aibo-blue to-aibo-signal
from-aibo-navy to-aibo-blue
from-blue-400 to-aibo-blue
from-purple-400 to-indigo-500
from-pink-400 to-rose-500
from-amber-400 to-orange-500
from-emerald-400 to-teal-500
from-aibo-signal to-emerald-600

Aplícalos con Tailwind:
  className="bg-gradient-to-br from-aibo-blue to-aibo-signal"

ANIMACIONES DISPONIBLES
=======================

animate-fadeIn        - Aparición suave
animate-slideIn       - Deslización desde abajo
animate-slideInFromLeft  - Deslización desde izquierda
animate-slideInFromRight - Deslización desde derecha
animate-scaleIn       - Escalamiento suave
animate-pulse-soft    - Parpadeo suave
animate-shimmer       - Brillo deslizante

Úsalas así:
  className="animate-slideIn"
  style={{ animationDelay: '100ms' }}

TIPS Y MEJORES PRÁCTICAS
========================

1. Siempre usa TypeformContainer para envolver tus páginas
2. Agrupa el contenido en TypeformCard
3. Usa TypeformHeading + subtitle para explicar cada paso
4. Una pregunta/sección importante por pantalla
5. Deja espacios en blanco generosos (espaciado)
6. Usa los gradientes vibrantes para diferenciar secciones
7. Agrega animaciones con delays escalonados:
   style={{ animationDelay: `${index * 50}ms` }}
8. Valida campos antes de permitir avanzar
9. Usa TypeformPhaseContainer para páginas de diagnóstico

---

PARA ACTUALIZAR OTRAS PÁGINAS:

1. Importa los componentes Typeform necesarios
2. Reemplaza el contenedor principal con TypeformContainer
3. Agrupa contenido en TypeformCard
4. Reemplaza inputs nativos con TypeformInput, etc.
5. Usa TypeformPhaseContainer para páginas de fase
6. Agrega animaciones con animate-* classes
7. Usa los gradientes vibrantes para los títulos

Ver: BusinessDiscoveryPage.improved.tsx para un ejemplo completo.
